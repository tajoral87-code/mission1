
# 코디세이 AI 올인원 과정 — 미션 2

## 프로젝트 소개

Python 기초 문법을 학습하며 터미널에서 실행되는 퀴즈 게임을 개발하는 프로젝트입니다.

주요 기능은 퀴즈 풀기, 퀴즈 추가, 퀴즈 목록 확인, 최고 점수 기록입니다.

## 개발 진행 상태

- [ ] Python 개발 환경 확인
- [ ] 기본 메뉴 구현
- [ ] Quiz 클래스 구현
- [ ] 기본 퀴즈 5개 작성
- [ ] 퀴즈 풀기 기능 구현
- [ ] 퀴즈 추가 및 목록 기능 구현
- [ ] JSON 데이터 저장
- [ ] Git 브랜치 병합 및 clone·pull 실습
